# 项目实战

本页面用于汇总课程中的阶段项目和最终综合项目。

## 综合项目

项目名称：**Cloud Native Todo Platform**

最终形态包括：

- Go Todo API 服务
- PostgreSQL 数据库
- Redis 缓存
- Nginx / Ingress 入口
- Dockerfile 与 Docker Compose
- Kubernetes YAML
- Helm Chart
- dev / test / prod 多环境配置
- CI/CD 与 GitOps
- Prometheus、Grafana、Loki / ELK
- HPA、RBAC、NetworkPolicy、TLS
- Operator 自动化管理
